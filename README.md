## Project Description

VisionGuard is an image classification and MLOps project
designed to distinguish AI-generated images from real images.

## Technology Stack

- Python 3.11
- TensorFlow / Keras
- Scikit-learn
- OpenCV
- DVC
- MLflow
- DagsHub
- Flask
- PostgreSQL
- Docker
- GitHub Actions

## Project Structure

- data/: Dataset storage
- src/: Source code
- scripts/: Execution scripts
- models/: Trained models
- outputs/: Generated results
- app/: Web application
- database/: Database configuration
- tests/: Automated tests
- configs/: Project configuration
- docs/: Documentation and screenshots
